# 改造方案：白标 + 后端打通

> 状态：方案阶段。先读 `调研与决策.md` 与本仓库根 `AGENTS.md`。

## 总体架构

```
hxai-admin (Go，已瘦身：只管 Octop 没有的三块)    Octop (本仓库产品底座)
┌─ 身份：账号目录 + OIDC IdP（待建） ──────────┐   ┌─ 实例内管理（原生，勿重复造）：
│   → /.well-known/openid-configuration ──────┼─►│   用户/角色模板/用户组、provider、
│   → /oauth/authorize|token|jwks             │  │   插件运行时、技能包+SkillHub、
├─ 供给：专家/插件/技能 生产与打包 ────────────┤  │   存储、审计、指标、SharedModels
│   → GET /api/market/experts|plugins（待建，  │  ├─ 市场消费端：experts/hub/{slug}/install
│      按 docs/private-market.md 契约）────────┼─►│   ← OCTOP_MARKET_REMOTE_ORIGIN 指过来
├─ 下发：客户端配置 /v1/client-config ────────┤  ├─ SSO：sso_oidc ← 指过来
│   features 开关 / labels 文案 / agentLinks  │  ├─ PostgreSQL/SQLite + 工作区存储
│   + handoff 配对 + client tokens            │  └─ Web Dashboard / IM / API / Wails 壳
└─────────────────────────────────────────────┘
        ▲ Bridge WS（用户级配对，2026-11-07 已实测通：probe/连接/跨端对话）
        │
桌面端 Octop（Wails 壳 + 内嵌 portable runtime = 本地 harness）
```

**边界原则**：Octop 管「实例内的一切」（用户/角色/用户组、provider、插件运行时、
技能包、存储、审计），hxai-admin 管「实例之上的供给面」（身份发行、市场内容、
客户端配置下发）。hxai-admin 里的 users 表定位是 SSO 身份域账号目录（含后台
操作员），不是 Octop 产品用户的副本。

**权限模型（两层，先不引入跨端维度）**：

| 层 | 管什么 | 载体 |
|---|---|---|
| 身份域（hxai-admin） | **你是谁**：账号目录、登录态、（待建）OIDC 签发；角色只管后台操作（admin/publisher/member），与产品权限无关 | users + sessions |
| 实例（每台 Octop） | **你能干什么**：角色模板（`users.role`，admin 全通/自定义 ULID 模板）+ ~40 个模块权限目录（`require_permission`，非 admin 按 `user.permissions` 勾选）+ 资源所有权（agent/thread/workspace 按 user_id，is_shared/用户组共享）+ `user_policies` 资源级策略 | users.role / permissions / user_policies / user_groups |

约定：**身份域只发身份，实例定权限**——不建第三套权限表，不做跨实例权限
同步；`/v1/client-config` 的 features/labels 只是界面开关与文案，不是安全
边界，真正鉴权永远在 Octop 实例的 require_permission + 所有权。

## 已验证的接口事实（勿重复调研）

- 登录：`POST /api/auth/login` → `{access_token, token_type, expires_in, user}`。
- OIDC 适配器：discovery `/.well-known/openid-configuration`（issuer 严格匹配）、
  JWKS 必需、id_token 仅 RS256/ES256、PKCE S256、nonce 校验。
- 私有市场：`GET {PORTAL}/api/market/{plugins,experts}` 全量拉取缓存 30s；
  目录条目内嵌详情字段（不再二次取 `/id`）。
- dashboard 构建：`cd dashboard && npm ci && NODE_ENV=production npm run build`
  → `src/hxai-octop/dashboard/`；产物不入库，部署必须构建+重启。
